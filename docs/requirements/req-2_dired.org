* 背景

Doom の =:emacs dired= モジュールはファイルマネージャ（Dirvish ベース）を提供する。現状
=init.el= では =dired= がフラグなしで有効化されている（=:emacs dired= 行）だけで、=config.el=
には dired 関連の設定が無い。そのため dired の挙動は素の既定のまま（コピー/移動先の補完なし・
再帰コピーの確認・隠しファイル表示やサイズ表記が既定の =ls= 切り替え）で、Dirvish の本格 UI
（=+dirvish=）やアイコン表示（=+icons=）も使われていない。

dired の使い勝手を上げるため、よく使う挙動変更の変数設定と、Dirvish/アイコンのモジュール
フラグ有効化を行う。

* 要求一覧

** req-2.1: dired の基本挙動を整える変数を設定すること（必須）

dired の操作性を上げる以下の挙動にすること。設定値はユーザー指定（=* タスクへの引き継ぎ= の
確定コードを正とする）。

- 2 画面表示時、コピー/リネームのデフォルト先を別ウィンドウの dired に合わせる（=dired-dwim-target=）。
- ディレクトリの再帰コピーを確認なしで常に行う（=dired-recursive-copies=）。
- =isearch= をファイル名に限定して検索できる（=dired-isearch-filenames=）。
- 一覧の =ls= 切り替えを「隠しファイル（=.= 除く）表示・種別記号付き・縦持ち・人間可読サイズ」に
  する（=dired-listing-switches= = =-AFlh=）。

** req-2.2: dired モジュールに =+dirvish= と =+icons= フラグを有効化すること（必須）

=init.el= の =:emacs dired= を =(dired +dirvish +icons)= にして、Dirvish の本格 UI とファイル
種別アイコン表示を有効にすること（=doom sync= が必要）。

- =+dirvish= — Dirvish の完全統合（モダンな dired インターフェース）。
- =+icons= — ファイル種別に応じたアイコンを dired バッファに表示する。

* タスクへの引き継ぎ

ユーザー指定の確定設定（req-2.1）。配置先・遅延ロードへの対応（=after!= の要否等）は
タスクで設計する。

#+begin_src emacs-lisp
(setq dired-dwim-target t)
(setq dired-recursive-copies 'always)
(setq dired-isearch-filenames t)
(setq dired-listing-switches "-AFlh")
#+end_src

* 非機能要求・制約

- 変数設定（req-2.1）の配置先は =config.el=。dired は遅延ロードされるため、既定値の上書きが
  確実に効くロードタイミングの扱い（素の =setq= か =after!= か）はタスクで設計する。
- モジュールフラグの有効化（req-2.2）は =init.el= の編集 + =doom sync= が必要。docker batch は
  init.el 変更時に自動で =doom sync= を走らせる。
- 検証環境の制約: =docker/= の検証コンテナ（Linux）で確認できるのは「変数が設定値になる」
  「=doom sync= がエラーなく完了し =dired +dirvish +icons= が有効になる」程度。=+icons= の実際の
  アイコン描画（nerd-icons フォント依存）や Dirvish のプレビュー（=imagemagick= 等の外部ツール
  依存）は GUI・環境依存のため、最終確認は macOS 上でユーザーに依頼する。

受け入れ確認手順:

- [ ] =dired-dwim-target= が =t= になっている
- [ ] =dired-recursive-copies= が =always= になっている
- [ ] =dired-isearch-filenames= が =t= になっている
- [ ] =dired-listing-switches= が =-AFlh= になっている
- [ ] =init.el= で =(dired +dirvish +icons)= が有効化され、=doom sync= がエラーなく完了する（=./docker/run.sh batch=）
- [ ] dired バッファでファイル種別アイコンが表示される（macOS 実機）
- [ ] Dirvish の UI（プレビュー等）が動作する（macOS 実機）
- [ ] 設定ロード時にエラーが出ない（=./docker/run.sh batch=）
