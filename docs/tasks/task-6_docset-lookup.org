* 背景

Dash 形式の docset を Emacs から（インストールから =eww= 閲覧まで）完結して使えるようにする。Dash.app には依存しない。

実現は doom の =:tools lookup +docsets= に乗る:

- =+docsets= で =dash-docs= と =consult-dash= が導入される（=consult-dash= は同梱。追加パッケージ不要）。
- docset 格納先 =dash-docs-docsets-path=（=doom-profile-data-dir/docsets/=）・閲覧 =dash-docs-browser-func= = =#'eww= はいずれも既定値が要求に合致するため、変数の上書きは行わない。
- =set-docsets!= は doom の lookup モジュールが提供するマクロ。利用頻度の高いコマンドは =SPC d= 配下に =map!= で集約する。

関連: [[file:task-5_lsp-languages.org][task-5 lsp-languages]]（同じ lookup 系の言語設定）。

** TODO [#A] req-6.1 init.el の lookup モジュールに +docsets フラグを付与

=init.el= の =:tools= にある素の =lookup= を =(lookup +docsets)= にする（現状 =init.el:101= は =lookup=）。

- 冪等性: 既に =(lookup +docsets)= であれば変更しない。素の =lookup= 行だけをアンカーに置換し、二重付与しない。
- これにより =dash-docs= / =consult-dash= が導入され、docset 格納先・=eww= 閲覧は既定値のまま満たされる（=config.el= への変数追加は無し）。
- 変更後は =doom sync= が必要（ホストはユーザーへ依頼、docker は =batch= / =screenshot= 前に自動実行）。
