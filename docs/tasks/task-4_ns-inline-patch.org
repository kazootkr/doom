* 背景

=ns-inline-patch=（NS port の IME 連携ビルドパッチ・適用済み）を使い、普段は英数を基底に、必要な
場面でだけ日本語を入力できるよう IME を制御する（[[file:../requirements/req-4_ns-inline-patch.org][req-4]]）。あわせて NS port + Emacs 30 系で
=diff-hl= がフリーズする既知の不具合（dgutov/diff-hl#230）を回避する。

採用方針（doom-first・参考実装）:

- =doom-first= 確認済み: =:os macos= / =:input= に =mac-ime-*= 相当の IME 制御は無く、=config.el= で
  独自に組む。
- =ns-inline-patch= 適用ビルドが提供する primitive を使う: =mac-input-method-mode=（連携の有効化）・
  =mac-default-input-source=（既定入力ソース）・=mac-ime-deactivate= / =mac-ime-activate=（IME の
  オフ/オン）・=mac-get-current-input-source=（fboundp 判定の踏み台）。これらは未適用ビルドには
  存在しないため、=(fboundp 'mac-input-method-mode)= をブロック先頭ガードにして対象外環境では
  ブロックごと no-op にする。
- 配線方法は takaxp/emacs.d を参考にする（=late-init.el= の =mac-input-method-mode= 有効化と
  =isearch= / =minibuffer-setup-hook= 連携、=utility.el= の =my-ime-off= 等）。ただし takaxp は
  =isearch= で IME をオフにする設定だが、req-4.4 は =isearch= 等で日本語入力を許可する方針なので、
  「=isearch= にはオフのフックを追加しない」点が takaxp と異なる。
- req-4.5 の =diff-hl-update-async= は doom の =:ui vc-gutter= が =diff-hl= の =:config= で
  =(or (> emacs-major-version 30) 'thread)= に設定する（[[file:../../../emacs/sources/doom+/modules/ui/vc-gutter/config.el][vc-gutter config.el]] 97 行）。本環境は
  Emacs 30.2 なので値は =thread=（Lisp スレッド非同期）になりフリーズの条件を満たす。CLAUDE.md の
  方針どおり =after! diff-hl= で =nil= に上書きしてスレッド非同期更新を止める（fringe 表示は維持）。

現状（[[file:../../config.el][config.el]]）: macOS/NS 固有の外観設定ブロック（45–65 行）はあるが IME 連携設定は無い。
=diff-hl-update-async= の上書きも無い（doom 既定の =thread= のまま）。

** fix-1: アプリスイッチ時の IME 引きずり（動作確認で判明した不具合）

task-4 実装後の macOS 実機確認で、次の不具合が判明した（[[file:../../config.el][config.el]] の IME 制御ブロックに対する追加修正）:

- ケース1: Emacs が evil ノーマルステートまたは =M-x=（minibuffer）のまま他アプリへスイッチすると、
  他アプリ（Notes.app 等）で IME を日本語入力モードに切り替えられない。切り替えても即座に英数へ戻される。
- ケース2: insert ステートのまま他アプリへスイッチした場合も、他アプリで日本語入力モードに切り替えられない。

根本原因: =mac-input-method-mode= は Emacs のフォーカス変化・=buffer-list-update= に IME 状態を同期する。
この同期は内部で =mac-toggle-input-source=（macOS の =TISSelectInputSource=）を呼び、システム全体の
入力ソースを書き換える。Emacs が非フォーカス（他アプリが前面）でもこの同期が走るため、ノーマルステート /
minibuffer で IME を英数に落とした状態（req-4.2 / req-4.3）のままスイッチすると、前面アプリの入力ソースを
Emacs の「英数」に引き戻してしまう。

修正方針: =mac-toggle-input-source= を around advice でラップし、=(frame-focus-state)= が真（Emacs フレームが
前面・フォーカスあり）のときだけ実体を呼ぶ。非フォーカス時は入力ソースを変更しないので、他アプリの IME
切り替えに干渉しない。

* やること

実装は =config.el= のみ（=doom sync= 不要。=packages.el= 変更不要）。追加は 2 か所:

1. IME 制御の =(when (and (eq system-type 'darwin) (featurep 'ns) (fboundp 'mac-input-method-mode)) ...)=
   ブロック（req-4.1〜4.4）を、既存の macOS 外観ブロック（65 行で閉じる）の直後・=display-line-numbers-type=
   の行（67 行付近）の前に追加する。
2. =diff-hl= の =after!= ブロック（req-4.5）を =config.el= 末尾（org-capture ブロックの後）に追加する。

冪等性: =add-hook= / =defvar= / =defun= / =setq= / =custom-set-variables= / =mac-input-method-mode 1=
はいずれも再評価しても同じ最終状態になる。fix-1 では =advice-add= を使うが、無名 =lambda= ではなく
名前付き関数をシンボルで登録する（=advice-add 'mac-toggle-input-source :around #'+ime/toggle-input-source-when-focused=）。
=advice-add= は同じシンボルを同じ位置に重複追加しないため、再評価しても二重登録されない。既に同等の
ブロックがあれば、新規追加せず内容を一致させる（テキストの重複を作らない）。

req-4.1〜4.4 の最終的なブロックは次の 1 つにまとめる（各見出しはこの中の該当部分を担当する）:

#+begin_src emacs-lisp
;; req-4.1〜4.4 (docs/requirements/req-4_ns-inline-patch.org)
;; ns-inline-patch（NS port の IME 連携パッチ）適用ビルド向けの IME 制御。
;; mac-* 関数はパッチ適用ビルドのみが提供するため、未適用ビルド・対象外環境（Linux/docker）では
;; fboundp ガードでブロックごと no-op になる。
(when (and (eq system-type 'darwin) (featurep 'ns)
           (fboundp 'mac-input-method-mode))
  ;; req-4.1: 既定入力ソースを macOS 標準の日本語 IME (Kotoeri) にし、IME 連携を有効化する。
  ;; 基底は英数（IME オフ）。入力ソース ID は macOS バージョンで変わりうるので、実機の
  ;; (mac-ime-input-source-list) で確認し、異なればこの 1 か所を合わせる。
  (when (fboundp 'mac-get-current-input-source)
    (custom-set-variables
     '(mac-default-input-source "com.apple.inputmethod.Kotoeri.RomajiTyping.Japanese")))
  (unless noninteractive
    (mac-input-method-mode 1))

  ;; req-4.2: evil ノーマルステートに入ったら IME を自動オフにする（コマンドキーの誤爆防止）。
  (add-hook 'evil-normal-state-entry-hook #'mac-ime-deactivate)

  ;; req-4.4: これらのコマンドに伴う minibuffer 入力では IME を自動オフにしない（日本語入力を許可）。
  ;; isearch 系は minibuffer-setup-hook を経由しないため列挙せず、「オフのフックを足さない」ことで
  ;; 日本語入力可のままにする。
  (defvar +ime-minibuffer-japanese-commands
    '(+default/search-project org-tags-view org-capture org-ctrl-c-ctrl-c)
    "minibuffer 入力で IME を自動オフにしないコマンド。")

  ;; req-4.3: minibuffer 読み取り開始時、例外コマンド以外では IME をオフにする（「M-x あ」対策）。
  (defun +ime/minibuffer-setup ()
    "例外コマンド以外の minibuffer 読み取りで IME をオフにする。"
    (unless (memq this-command +ime-minibuffer-japanese-commands)
      (mac-ime-deactivate)))
  (add-hook 'minibuffer-setup-hook #'+ime/minibuffer-setup))
#+end_src

** TODO [#A] req-4.1 ns-inline-patch の IME 連携を有効化し既定入力ソースを macOS 標準 IME にする

上記ブロックの先頭ガード =(when (and (eq system-type 'darwin) (featurep 'ns) (fboundp 'mac-input-method-mode)) ...)=
と、その中の =mac-default-input-source= 設定・=(mac-input-method-mode 1)= を実装する。

- =mac-default-input-source= は macOS 標準の日本語 IME（Kotoeri）にする。既定値は
  =com.apple.inputmethod.Kotoeri.RomajiTyping.Japanese=。実機の =(mac-ime-input-source-list)= で
  正しい ID を確認し、macOS のバージョンで異なる場合はこの 1 か所だけを合わせる（README 例の
  Google 日本語入力 ID は使わない）。
- =(mac-input-method-mode 1)= は =(unless noninteractive ...)= で囲む（batch での副作用回避）。
- 編集・コマンドの基底は英数（IME オフ）。

** TODO [#A] fix-1 アプリスイッチ時に IME 状態を他アプリへ引きずらせない

IME 制御ブロック（=config.el= の =(when (and (eq system-type 'darwin) (featurep 'ns) (fboundp 'mac-input-method-mode)) ...)=）
内、=minibuffer-setup-hook= への =add-hook= の後（ブロック末尾）に、=mac-toggle-input-source= の around
advice を追加する。Emacs が前面（フォーカスあり）のときだけ入力ソースを変更し、非フォーカス時は他アプリの
IME 切り替えに干渉しないようにする。

- =mac-toggle-input-source= は =ns-inline-patch= 適用ビルドが提供するため、ブロック先頭の =fboundp= ガード
  で未適用ビルド・対象外環境（Linux/docker）では advice 自体が追加されない（no-op）。
- advice は無名 =lambda= にせず、名前付き関数 =+ime/toggle-input-source-when-focused= を =defun= してから
  シンボルで登録する（冪等性: 再評価でも二重登録されない。関数名は既存の =+ime/= プレフィックスに倣う）。

#+begin_src emacs-lisp
  ;; fix-1: アプリスイッチ時に IME 状態を他アプリへ引きずらせない。
  ;; mac-input-method-mode はフォーカス変化・buffer-list-update に IME 状態を同期し、内部で
  ;; mac-toggle-input-source（TISSelectInputSource）を呼んでシステム全体の入力ソースを書き換える。
  ;; Emacs が非フォーカスの間も同期が走り前面アプリの入力ソースを Emacs の状態（英数）に引き戻すため、
  ;; frame-focus-state が真（Emacs が前面）のときだけ入力ソースを変更する。
  (defun +ime/toggle-input-source-when-focused (orig &rest args)
    "Emacs フレームがフォーカスを持つときだけ ORIG（mac-toggle-input-source）を実行する。"
    (when (frame-focus-state) (apply orig args)))
  (advice-add 'mac-toggle-input-source :around #'+ime/toggle-input-source-when-focused)
#+end_src

** TODO [#A] req-4.5 diff-hl の非同期更新を無効化してフリーズを回避する

=config.el= 末尾に次を追加する。doom の =:ui vc-gutter= が =diff-hl= の =:config= で
=diff-hl-update-async= を Emacs 30 系では =thread= にするため、=after! diff-hl= でその後に =nil=
で上書きし、スレッド非同期更新（フリーズの原因）を止める。非マカ環境でも =nil= は安全
（同期更新になるだけで fringe の diff 表示は維持）なのでガードしない。=setq= は冪等。

#+begin_src emacs-lisp
;; req-4.5 (docs/requirements/req-4_ns-inline-patch.org)
;; doom の :ui vc-gutter は Emacs 30 系で diff-hl-update-async を 'thread にする。macOS NS port +
;; Emacs 30 + スレッド非同期更新で diff-hl がフリーズする (dgutov/diff-hl#230) ため、非同期更新を
;; 無効化する。doom が diff-hl の :config で設定するため after! で上書きする（fringe 表示は維持）。
(after! diff-hl
  (setq diff-hl-update-async nil))
#+end_src
