* どの要求に基づくタスクか

- [[file:../requirements/req-3_org-notes.org][req-3 org-notes]]

* 背景

org-mode で日誌・メモ・ToDo を 1 つのノート用ディレクトリ（=notes=）配下にまとめて記録・管理する
（[[file:../requirements/req-3_org-notes.org][req-3]]）。

採用方針（doom-first・単一の真実源）:

- ノート用ルートを =my-dev-notes-dir= 1 か所で定義し、=org-directory= をそれに合わせる。
- doom の =:lang (org +journal)= は =org-journal-dir= を =org-directory= 配下の =journal/= に
  既定設定する（[[file:../../../emacs/sources/doom+/modules/lang/org/contrib/journal.el][doom journal.el]] の =:config= で
  =(setq org-journal-dir (expand-file-name org-journal-dir org-directory))=）。よって
  =org-directory= = =my-dev-notes-dir= とするだけで、日誌は =notes/journal/= に保存される
  （req-3.2 の保存先が doom 既定でそろう。=org-journal-dir= を自前で書く必要はない）。
- =org-journal= は =packages.el= 追加不要。=init.el= の =org= → =(org +journal)= フラグ追加と
  =doom sync= だけで導入される。
- agenda/タグ検索/TODO 一覧の対象は、doom 既定（=(list org-directory)= = 非再帰）では =notes=
  配下を横断できないため、=notes= 配下のディレクトリを =org-agenda-files= に明示列挙する。

現状（[[file:../../config.el][config.el]]）: =org-directory= は =~/org/=(73 行)。=org-journal= / =org-capture= /
=org-agenda-files= の設定は無い。=init.el= の =:lang= は =org=（フラグなし、161 行）。

注意: =notes= の実パスはユーザー指定が無いため既定値 =~/notes/= を置く。実環境に合わせて
=my-dev-notes-dir= の 1 か所を変えれば全設定が追従する。docker/Linux にはこのパスが無いので、
agenda 設定はパス存在をガードして対象外環境で no-op にする。

追加（req-3.5、req-3.1〜3.4 の運用開始後に判明）: TODO の状態キーワードが 16 個あり選択肢が
多すぎる。これは doom の =:lang org= が =org-todo-keywords= に 3 本の =sequence= を設定している
既定値で、この DOOMDIR では未設定のため既定がそのまま効いている。=notes= 配下で実使用がある状態は
=TODO= / =DONE= / =STRT= の 3 つのみのため、これらを含む 5 状態（=TODO= / =STRT= / =WAIT= /
=DONE= / =KILL=）へ絞る。既存見出しが TODO 状態として認識されなくなる退行を出さないことが条件。

** DONE [#A] req-3.1 ノート用ルートを定義し =org-directory= を合わせる

=config.el= の既存 =(setq org-directory "~/org/")=（73 行、コメント 71–72 行の直後）を、以下に
置き換える。=my-dev-notes-dir= はキャプチャテンプレート等から参照される単一の真実源。末尾の
=/= は =(concat my-dev-notes-dir "Reminder.org")= が成立するために必須。=defvar= / =setq= は
冪等。

#+begin_src emacs-lisp
;; req-3.1 (docs/requirements/req-3_org-notes.org)
;; メモ・日誌・ToDo を置くノート用ルートディレクトリ。journal の保存先・capture の出力先・
;; agenda の対象は、すべてこの 1 つの定義を参照する。実環境に合わせてここを変える。
;; 末尾の "/" は capture の (concat my-dev-notes-dir "Reminder.org") のため必須。
(defvar my-dev-notes-dir "~/notes/"
  "メモ・日誌・ToDo を置くノート用ルートディレクトリ。")

;; org-directory を notes ルートに合わせる（org ロード前に設定する必要がある）。
;; これにより :lang (org +journal) は org-journal-dir を {notes}/journal/ に既定設定し、
;; req-3.2 の保存先（notes/journal/）が自動でそろう。
(setq org-directory my-dev-notes-dir)
#+end_src

** DONE [#A] req-3.2 =(org +journal)= を有効化し org-journal の書式を設定する

1. =init.el= の =:lang= の =org= 行（161 行）を =(org +journal)= に変更する（=doom sync= 必要）。
   既に =(org +journal)= なら変更しない。
   - 変更前: =       org               ; organize your plain life in plain text=
   - 変更後: =       (org +journal)    ; organize your plain life in plain text=

2. =config.el= に org-journal の書式設定を追加する（末尾の dired =after!= ブロックの後）。
   org-journal は遅延ロードされ doom の =:config= が走るため、=after!= でその後に適用して要求値を
   勝たせる。=setq= は冪等。保存先 =org-journal-dir= は doom が =org-directory=（= =my-dev-notes-dir=）
   配下の =journal/= に設定するため、ここでは書式のみ指定する。

#+begin_src emacs-lisp
;; req-3.2 (docs/requirements/req-3_org-notes.org)
;; org-journal の書式設定。保存先 org-journal-dir は doom (+journal) が org-directory 配下の
;; "journal/" に設定するため、ここでは書式のみ指定する。
(after! org-journal
  (setq org-journal-file-format "org-journal_%Y-%m-%d.org")
  (setq org-journal-date-prefix "#+TITLE: ")
  (setq org-journal-date-format "%Y/%m/%d (%a)")
  (setq org-journal-time-prefix "* TODO ")
  (setq org-journal-file-header "#+STARTUP: indent\n#+STARTUP: showall\n#+STARTUP: nolineimages\n#+STARTUP: hidestars"))
#+end_src

** DONE [#B] req-3.3 agenda/タグ検索/TODO 一覧を =notes= 配下の org 全体に向ける

=config.el= に以下を追加する（org-journal ブロックの後）。=notes= ルートと全サブディレクトリを
=org-agenda-files= に列挙する。各ディレクトリエントリは agenda 構築のたびに =*.org= を再走査する
ため、新規日誌も自動で含まれる。org ロード前に設定すれば doom 既定（=(list org-directory)=）に
=unless= で上書きされない。=notes= が無い環境（docker/Linux）では =directory-files-recursively=
がエラーになるため =file-directory-p= でガードし、その場合は =org-agenda-files= を変更しない
（no-op）。=setq= は冪等。

#+begin_src emacs-lisp
;; req-3.3: タグ検索・agenda・TODO 一覧の対象を notes 配下の org 全体にする。
;; notes ルートと全サブディレクトリを列挙（各ディレクトリは agenda 構築時に *.org 再走査）。
;; notes が無い環境では directory-files-recursively がエラーになるためガードして no-op にする。
(when (file-directory-p my-dev-notes-dir)
  (setq org-agenda-files
        (cons (directory-file-name my-dev-notes-dir)
              (seq-filter #'file-directory-p
                          (directory-files-recursively my-dev-notes-dir "" t)))))
#+end_src

** DONE [#B] req-3.4 org-capture で ToDo を =notes/Reminder.org= に書き留める

=config.el= に以下を追加する（agenda ブロックの後）。出力先は =my-dev-notes-dir= 配下の
=Reminder.org=。=after! org-capture= はユーザー指定の確定コードに従う。=setq= は冪等。

#+begin_src emacs-lisp
;; req-3.4: org-capture で ToDo を notes/Reminder.org に書き留める。
(after! org-capture
  (setq org-capture-templates
        `(("t" "Todo" entry
           (file+headline ,(concat my-dev-notes-dir "Reminder.org") "■ ToDo")
           "* TODO %? [Created by %t]")
          ("s" "Scheduled Todo" entry
           (file+headline ,(concat my-dev-notes-dir "Reminder.org") "■ Scheduled Todo")
           "* TODO %? # SCHEDULED: %^t"))))
#+end_src

** TODO [#B] req-3.5 TODO 状態キーワードを 5 つに絞る

=config.el= の =after! org-capture= ブロックの後（=after! diff-hl= ブロックの前）に以下を追加する。
既に =after! org= の =org-todo-keywords= 設定があれば内容を要求値に合わせるだけで、ブロックを
増やさない。

doom の =:lang org= は =:config= 内で =org-todo-keywords= に 3 本の =sequence=（16 状態）を
設定するため、素の =setq= では doom 側に上書きされる。=after! org= でモジュール設定の後に適用して
要求値を勝たせる（=after! dired= / =after! diff-hl= と同じ理由）。=setq= は冪等。

=org-todo-keyword-faces= は変更しない。doom 既定に =STRT= / =WAIT= / =KILL= の色付けが含まれて
おり、残す 5 状態はそのまま色が付く。対応キーワードが無くなる =[-]= / =[?]= / =PROJ= / =NO= の
エントリは参照されなくなるだけで無害。

#+begin_src emacs-lisp
;; req-3.5 (docs/requirements/req-3_org-notes.org)
;; TODO 状態を実際に使う 5 つに絞る。doom の :lang org が :config で org-todo-keywords に
;; 16 状態（3 本の sequence）を設定するため、after! でその後に適用して要求値を勝たせる。
;; 既存ノートで使用中の TODO / DONE / STRT は必ず残す（既存見出しが素のテキストに落ちるため）。
(after! org
  (setq org-todo-keywords
        '((sequence "TODO(t)" "STRT(s)" "WAIT(w)" "|" "DONE(d)" "KILL(k)"))))
#+end_src
