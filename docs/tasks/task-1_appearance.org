* 背景

Doom Emacs の外観（フォント・テーマ・日本語表示・スクロール）を整える。現状 =config.el= は
doom 既定テンプレートのままで、=doom-theme= は =doom-one=、=doom-font= 未設定、日本語フォントの
割り当て・=line-spacing=・macOS の anti-aliasing 設定が無い。日本語フォントを明示しないと CJK
統合で中国語字形になったり豆腐（□）になるため、macOS の Hiragino 系を割り当てる。

実装は 2 ファイルにまたがる:

- =config.el=（=doom sync= 不要）— doom 変数（=doom-font= / =doom-variable-pitch-font= /
  =doom-theme=）、=line-spacing=、および macOS 固有設定（anti-aliasing・日本語フォントセット・
  =face-font-rescale-alist=）を darwin/NS ガード内に置く。
- =init.el=（=doom sync= 必要）— =:ui= モジュールの有効化。複数モジュールの編集はまとめて
  1 回の =doom sync= で反映する（docker batch は init.el 変更時に自動で sync する）。

macOS 固有要素（JetBrains Mono / Hiragino / anti-aliasing / 表示幅）は docker（Linux）で検証
できないため、最終確認はユーザーに依頼する。

** fix-1: org の src ブロック内で選択範囲が見えない（動作確認で判明した不具合）

req-1.4 のテーマ適用後、macOS 実機での確認で次の不具合が判明した:

- org の =#+begin_src= 〜 =#+end_src= 内でリージョンを選択しても背景色が変わらず、選択範囲を視認できない。

根本原因: =doom-solarized-dark-high-contrast= が =region= とコードブロック系 face に同じ色を割り当てている。
テーマ定義（=doom-solarized-dark-high-contrast-theme.el=）で =(region base0)=・
=((org-block &override) :background base0)=・=((org-block-begin-line &override) ... :background base0)= と
なっており、いずれも =base0= = =#01323d=。docker 上の実測でも =default #002732= / =region #01323d= /
=org-block #01323d= / =org-block-begin-line #01323d= / =org-block-end-line #01323d= と一致を確認した。
ブロック外は地の色 =#002732= と =region= の =#01323d= に差があるため選択が見えるが、ブロック内だけ差がゼロになる。

修正方針: =org-block= / =org-block-begin-line= / =org-block-end-line= の背景をテーマの =base3=（=#13383C=）に
して =region= と分離する。=base3= は doom-themes-base での =org-block= の既定値で、地の色 =#002732= より明るいため
コードブロックの輪郭も保たれる。

** fix-2: 対象外環境（Linux/docker）で可変ピッチフォント指定が初期化を止める（動作確認で判明した不具合）

fix-1 の docker 検証中に次の不具合が判明した:

- docker（Linux）で GUI 起動すると =Could not find a font on your system: Hiragino Kaku Gothic ProN= が出て
  初期化が中断し、テーマが適用されないまま停止する。

根本原因: req-1.3 の =doom-variable-pitch-font=（Hiragino Kaku Gothic ProN）が =config.el= のトップレベル
（darwin/NS ガードの外）に置かれている。Hiragino は macOS 専用フォントのため、Linux では doom のフォント適用が
=after-init-hook= で =user-error= を投げ、以降の初期化（テーマ適用を含む）が走らない。req-1 の非機能要求
「macOS 固有の設定は darwin / NS port を判定するガード内に置き、対象外環境では no-op」に反しており、完了条件
「対象外環境で macOS 固有設定が no-op となり、エラーにならない」も実態としては満たせていない。

修正方針: =doom-variable-pitch-font= の =setq= を既存の darwin/NS ガードブロック内へ移す。

* やること

実装対象は =config.el= と =init.el=。=config.el= の doom 変数・=line-spacing= はトップレベルの
=setq= で、macOS 固有設定は 1 つの =(when (and (eq system-type 'darwin) (featurep 'ns)) ...)=
ガードブロック内にまとめる（このブロックは現状存在しないので新設し、以降はこのブロックを
アンカーに追記する）。=init.el= の各モジュールは対応するコメント行のコメントを外す形で一意に
有効化する（既に有効なら変更しない）。

** DONE [#A] req-1.4 テーマを =doom-solarized-dark-high-contrast= にする

=config.el= の =(setq doom-theme 'doom-one)= を以下に変更する。

#+begin_src emacs-lisp
(setq doom-theme 'doom-solarized-dark-high-contrast)
#+end_src

** DONE [#A] req-1.1 主フォントを JetBrains Mono・サイズ 15、行間 1.2 倍、合字を有効化

=config.el= のトップレベル（ガード外でよい。未インストール環境ではフォールバックするだけで
エラーにならない）に以下を置く。

#+begin_src emacs-lisp
(setq doom-font (font-spec :family "JetBrains Mono" :size 15))
;; 既定行高の 0.2 倍を行間に加える = 行の高さ約 1.2 倍
(setq-default line-spacing 0.2)
#+end_src

合字（リガチャ）は =:ui ligatures= モジュールで有効化する。=init.el= の =;;ligatures= 行の
コメントを外して =ligatures= にする（=doom sync= 必要）。=doom-symbol-font= は未設定のままで
よい（既定で合字描画に支障しないことを確認する）。

- 前提: JetBrains Mono が OS にインストール済みであること。未インストールなら
  https://www.jetbrains.com/ja-jp/lp/mono/ からの導入をユーザーに促す。

** DONE [#A] req-1.2 macOS で anti-aliasing 表示する

=config.el= に新設する darwin/NS ガードブロック内に置く。NS port 以外（Linux 等）では
ブロックごと評価されず no-op になる。

#+begin_src emacs-lisp
(when (and (eq system-type 'darwin) (featurep 'ns))
  (setq ns-antialias-text t))
#+end_src

** DONE [#A] req-1.3 日本語を日本語フォントで表示し、全角幅を半角の 2 倍にそろえる

同じ darwin/NS ガードブロック内に、日本語フォントセットの割り当て・表示幅調整・可変ピッチ
フォントを追加する。日本語フォントセットは =after-setting-font-hook=（doom がフォント適用後に
走らせる。=:ui unicode= の unicode-fonts より後に評価されるため req-1.6 の上書きに勝つ）で
適用し、初期ロード時にも一度呼ぶ。

#+begin_src emacs-lisp
(defun +appearance/set-japanese-font ()
  "default フォントセットに Hiragino 系の日本語フォントを割り当てる。"
  (dolist (charset '(japanese-jisx0208 katakana-jisx0201 cp932))
    (set-fontset-font t charset (font-spec :family "Hiragino Sans")))
  ;; かな・約物（U+3000–30FF）と漢字（U+4E00–9FFF）
  (set-fontset-font t '(#x3000 . #x30ff) (font-spec :family "Hiragino Sans"))
  (set-fontset-font t '(#x4e00 . #x9fff) (font-spec :family "Hiragino Sans")))

(add-hook 'after-setting-font-hook #'+appearance/set-japanese-font)
(+appearance/set-japanese-font)

;; 全角日本語の表示幅を半角英数の整数倍（2 倍）にそろえる
(add-to-list 'face-font-rescale-alist '(".*Hiragino.*" . 1.0))
#+end_src

- 表示幅の判断ルール: 上記 rescale 係数（既定 =1.0=）を起点に、org テーブルの罫線が縦にそろう
  まで（= 全角 1 文字 = 半角 2 文字幅になるまで）係数を調整する。macOS 上での目視で確定する。
- 可変ピッチ（地の文）フォントは darwin/NS ガードブロック内に設定する（配置は fix-2 で確定）。
  日本語が崩れない（中華フォント化・豆腐化しない）ことを優先し、ラテン・日本語とも収まる比例
  フォントを使う:

#+begin_src emacs-lisp
(setq doom-variable-pitch-font (font-spec :family "Hiragino Kaku Gothic ProN" :size 15))
#+end_src

  等幅が必要なコード・org テーブルは =doom-font=（JetBrains Mono）のまま保たれること。

** DONE [#B] req-1.6 appearance 関連の =:ui= モジュールを有効化する

=init.el= で以下のコメントを外して有効化する（各行のコメントを外すだけの一意な編集。
=doom sync= 必要）。

- =;;unicode= → =unicode=
- =;;indent-guides= → =indent-guides=
- =;;nav-flash= → =nav-flash=
- =;;(emoji +unicode)= → =(emoji +unicode)=

=unicode= 有効化後に req-1.3 の日本語表示が退行しないことを確認する（=+appearance/set-japanese-font=
が =after-setting-font-hook= 後段で再適用するため上書きを取り戻せる想定）。退行する場合は
=doom-symbol-font= や日本語フォントセットの優先順位を調整する。初回は unicode-fonts キャッシュ
生成で時間がかかる。macOS で =void-variable= エラーが出たら unicode-fonts キャッシュを削除して
再起動する。

** DONE [#C] req-1.5 ピクセル単位のスムーススクロール

=init.el= の =;;smooth-scroll= 行を =(smooth-scroll +interpolate)= にして有効化する
（=ultra-scroll= でピクセル平滑、=good-scroll= で PgUp/PgDn・=C-d=/=C-u= の補間。=doom sync= 必要）。
必須要求（req-1.1〜1.4）より優先度は低い。

** TODO [#A] fix-1 org のコードブロック系 face の背景を =base3= にして =region= と分離する

=config.el= 末尾（req-6.2 の =set-docsets!= の後、フレーム透過設定の前）に =custom-set-faces!= を追加する。
=custom-set-faces!= は doom の =doom-customize-theme-hook= 経由でテーマロード後に再適用されるため、=after!= や
適用順の考慮は不要（再評価しても同じ最終状態になる）。色はハードコードせず =(doom-color 'base3)= でテーマの
パレットから引く。既に同等のブロックがあれば新規追加せず内容を一致させる。

#+begin_src emacs-lisp
;; fix-1 (docs/tasks/task-1_appearance.org)
;; doom-solarized-dark-high-contrast は region と org-block 系 face の双方に base0 (#01323d) を割り当てる
;; ため、src ブロック内の選択範囲が視認できない。org-block 系の背景をテーマの base3 (#13383C) にして
;; region と分離する。custom-set-faces! はテーマロード後に再適用されるので適用順の考慮は不要。
(custom-set-faces!
  `((org-block org-block-begin-line org-block-end-line)
    :background ,(doom-color 'base3)))
#+end_src
