* 背景

dired の操作性を上げるため、挙動変更の変数設定（req-2.1）と Dirvish/アイコンのモジュール
フラグ有効化（req-2.2）を行う。

実装上の注意: doom の =:emacs dired= モジュールは一部の変数をパッケージロード時に設定する。
=dired-dwim-target= / =dired-recursive-copies= は =use-package! dired= の =:init= で、
=dired-listing-switches= は =:config=（ロード時）で =-ahl -v --group-directories-first= に
設定される。したがって =config.el= トップレベルの素の =setq= では =dired-listing-switches= が
doom の =:config= に上書きされてしまう。要求値を確実に勝たせるため、4 変数とも
=(after! dired ...)= でモジュール設定の後に適用する（CLAUDE.md の遅延ロード方針）。

実装は 2 ファイルにまたがる:

- =config.el=（=doom sync= 不要）— req-2.1 の 4 変数を =after! dired= で設定。
- =init.el=（=doom sync= 必要）— req-2.2 の =dired= 行にフラグ追加。

=+icons= の実アイコン描画（nerd-icons フォント依存）と Dirvish のプレビューは docker（Linux）
で検証できないため、最終確認は macOS 上でユーザーに依頼する。

* やること

実装対象は =config.el= と =init.el=。

** TODO [#A] req-2.1 dired の基本挙動の変数を =after! dired= で設定する

=config.el= に以下の =after!= ブロックを追加する。doom の dired モジュール設定（=:config= の
=dired-listing-switches= 上書き含む）の後に適用され、要求値が確実に勝つ。=setq= は冪等なので
再実行しても収束する。

#+begin_src emacs-lisp
;; req-2.1 (docs/requirements/req-2_dired.org)
;; dired は遅延ロードされ、doom の :config が dired-listing-switches を上書きするため、
;; after! でモジュール設定の後に適用して要求値を確実に効かせる。
(after! dired
  (setq dired-dwim-target t)
  (setq dired-recursive-copies 'always)
  (setq dired-isearch-filenames t)
  (setq dired-listing-switches "-AFlh"))
#+end_src
